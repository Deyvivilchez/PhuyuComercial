PHUYU - SERVIDOR LOCAL PHP 7.4
============================

Copia el bloque que necesites y pegalo en una terminal de PowerShell.
Las lineas que empiezan con # son comentarios.

INICIAR EL SERVIDOR
------------------

# Inicia PHP 7.4 con el router local, en segundo plano.
# No necesitas cambiar la version de PHP de XAMPP.
# Ejecuta este comando una sola vez por sesion de trabajo.
powershell -ExecutionPolicy Bypass -File C:\php74\phuyu-local\iniciar-phuyu.ps1

# Luego abre esta direccion en tu navegador:
# http://127.0.0.1:8080/

# Cerrar la terminal no detiene el servidor.
# Si el puerto 8080 ya esta ocupado, no se podra iniciar otra instancia.

DETENER EL SERVIDOR
------------------

# Busca el proceso que escucha en el puerto local de Phuyu.
$phuyuServidor = Get-NetTCPConnection -LocalAddress 127.0.0.1 -LocalPort 8080 -State Listen -ErrorAction SilentlyContinue

if ($phuyuServidor) {
    # Verifica que sea el ejecutable PHP 7.4 antes de detenerlo.
    $phuyuProceso = Get-Process -Id ($phuyuServidor.OwningProcess | Select-Object -Unique) -ErrorAction SilentlyContinue
    if ($phuyuProceso -and $phuyuProceso.Path -eq 'C:\php74\php.exe') {
        Stop-Process -Id $phuyuProceso.Id
        Write-Host 'Servidor de Phuyu detenido.'
    } else {
        Write-Host 'El puerto 8080 pertenece a otro proceso. No se detuvo.'
    }
} else {
    Write-Host 'El servidor de Phuyu ya esta detenido.'
}
